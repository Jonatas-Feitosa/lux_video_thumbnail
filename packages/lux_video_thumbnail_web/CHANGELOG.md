## 1.0.0

* Initial browser implementation with automatic Flutter registration and typed interop.
* Support Blob/byte/HTTP(S) sources and JPEG/PNG/WebP canvas output.
* Serialize seeks, preserve unknown duration and recover large seek discrepancies.
* Bound asynchronous waits, queues, sessions and image resources; release owned URLs.
* Return bytes and explicitly reject native filesystem saving on web.
